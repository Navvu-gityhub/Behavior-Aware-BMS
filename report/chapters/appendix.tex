\begin{center}
\textbf{DATA AVAILABILITY STATEMENT}
\end{center}

The three public datasets used in this work are available from their providers and are not redistributed with the project. The NASA Prognostics Center of Excellence battery data set \cite{saha2007} is published in the NASA Prognostics Data Repository. The CALCE CS2 and CX2 prismatic cell cycling series \cite{calce} is published by the Center for Advanced Life Cycle Engineering at the University of Maryland. The Oxford Battery Degradation Dataset~1 \cite{howey2017oxford} is published by the University of Oxford under the digital object identifier 10.5287/bodleian:KO2kdmYGg. Each dataset carries the terms of its own provider, which apply to any reuse. After download, the archives are placed in \texttt{data/raw/nasa/}, \texttt{data/raw/calce/} and \texttt{data/raw/oxford/}, which the repository excludes from version control. When a raw archive is absent, the validation script skips the stages that need it and states the reason, and does not fail.

The results derived from these datasets are available in the project repository. Every metric, table and per-cell result quoted in this report is stored as a text file under \texttt{reports/}\allowbreak\texttt{metrics/}, and the figures built from them are stored under \texttt{reports/}\allowbreak\texttt{figures/}. A reader can therefore check each reported number without downloading any raw data, and can regenerate the files from the raw data with the scripts listed in Appendix~B.

The bench-rig captures recorded by the authors, including the two real captures discussed in Chapter~\ref{ch:results}, are committed as text files under \texttt{data/interim/}, together with the hardware telemetry log kept in the repository. They were recorded from a single commercial 18650 cell at rest and contain voltage, temperature and timing values only. They contain no personal data and no data from any private vehicle or fleet. The fleet shown by the dashboard in Chapter~\ref{ch:implementation} is produced by the project's own simulator and is labelled as simulated wherever it is displayed. The CAN decoding example is based on the publicly documented message of the Open Vehicles Monitoring System for the Renault Twizy.

The source code of the system, the firmware, the tests, the architecture decision records and the documentation are available in the project repository at \url{https://github.com/Navvu-gityhub/Behavior-Aware-BMS} under the MIT licence. The system runs on a fresh clone without hardware, a database, an access key or a dataset download, as described in Appendix~C.

\chapter*{APPENDIX C}
\addcontentsline{toc}{chapter}{APPENDIX C}

\begin{center}
\textbf{Reproducing the System and the Results}
\end{center}

The repository is \url{https://github.com/Navvu-gityhub/Behavior-Aware-BMS}. The commands below run on a fresh clone with no hardware, no database, no API keys and no dataset download.

\begin{small}
\begin{verbatim}
git clone \
    https://github.com/Navvu-gityhub/Behavior-Aware-BMS.git
cd Behavior-Aware-BMS
pip install -r requirements-dev.txt

python main.py                     # end-to-end run
python scripts/run_serial_demo.py  # emulated rig
python scripts/health_report.py --serial \
    data/interim/rig_stage_b_voltage_verified.txt
python -m pytest tests/ -q         # the test suite
docker compose up                  # API, gateway, client
\end{verbatim}
\end{small}

With the CALCE data downloaded, the report card of a real cell as it read at a given cycle is printed by

\begin{small}
\begin{verbatim}
python scripts/health_report.py --calce \
    data/raw/calce/CS2/Type2/CS2_35.zip --upto-cycle 90
\end{verbatim}
\end{small}

The raw CALCE, NASA and Oxford data are not redistributed; their sources are given in Appendix~A.

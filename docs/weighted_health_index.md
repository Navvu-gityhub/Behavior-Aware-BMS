
# Battery Aging Budget + Weighted Health Index

Battery Aging Budget:
Initial budget = 100

Penalty factors:
- Stress
- Temperature
- Deep discharge
- Fast charging
- Aggressive discharge
- SOC abuse

Health Index:
HI = 100 - Aging Budget

Battery States:
0-29     HEALTHY
30-59    WARNING
60-79    DEGRADED
80-100   CRITICAL

This framework is suitable for:
- EV BMS
- Embedded implementation
- Predictive maintenance
- Battery Guardian AI

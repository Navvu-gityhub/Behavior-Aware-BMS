# Archive

Delivery reports, acceptance checklists and team updates from the project's
first weeks, kept for provenance and moved here on 2026-09-09.

They describe an earlier state of the system and several conclusions that have
since been withdrawn — the `capacity_loss` target they treat as sound was later
shown to be 96% measurement noise, and the method rankings they quote do not
reproduce. **Do not cite a figure from this directory.**

Current: `README.md`, `docs/architecture.md`, `docs/final_report.md`,
`docs/roadmap.md`, and `docs/adr/` for how decisions were actually reached.

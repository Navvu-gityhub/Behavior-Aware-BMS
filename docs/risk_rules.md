
# T17 Risk Classification Rules

Risk Categories

LOW:
0-39

MEDIUM:
40-59

HIGH:
60-79

CRITICAL:
80-100

Features Used:
- average stress
- average temperature
- deep discharge duration
- fast charge duration
- aggressive discharge count
- average SOC

Recommendations:
- Follow 20-80 charging rule
- Reduce fast charging
- Avoid deep discharge
- Reduce thermal exposure
